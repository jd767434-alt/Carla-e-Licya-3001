LUMIÈRE BEAUTY — SITE DEMONSTRATIVO

Arquivos:
- index.html: estrutura da loja
- style.css: estilos e layout responsivo
- script.js: catálogo, pesquisa, filtros, ordenação e carrinho

Como abrir no VS Code:
1. Extraia o arquivo ZIP.
2. Abra a pasta "beleza-cosmeticos" no Visual Studio Code.
3. Abra o arquivo index.html no navegador; ou use a extensão Live Server para visualizar.

Funcionalidades:
- Layout responsivo para desktop e celular.
- Catálogo demonstrativo de cosméticos.
- Busca de produtos, filtros por categoria e ordenação por preço/nome.
- Carrinho com adicionar, remover e alterar quantidades.
- Carrinho salvo no navegador com localStorage.
- Indicador de progresso para frete grátis demonstrativo.
- Formulário de newsletter com resposta simulada.

Observações:
- As imagens e fontes são carregadas da internet; é necessária conexão para visualizá-las.
- Este é um protótipo front-end. O botão de finalizar pedido não processa pagamentos, e a newsletter não envia dados a um servidor.
- Para uma loja real, conecte backend, estoque, frete e uma plataforma de pagamento segura.
